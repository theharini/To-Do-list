# 📝 To-Do List Web App

A simple and responsive To-Do List application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Data saved using LocalStorage
- Tasks remain even after page refresh
- Clean and responsive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage API

## 📂 Project Structure

```
To-Do-List/
│── index.html
│── style.css
│── todo.js
│── icon.png
│── checked.png
│── unchecked.png
```

## 💡 How It Works

- User enters a task in the input field.
- Clicking **Add** creates a new list item.
- Clicking on a task marks it as completed.
- Clicking the × icon deletes the task.
- All tasks are stored in LocalStorage.
